# COMMUNICATION CHANNELS

## Supported Channels (MVP)

### Native
- Email (send + log)

### Deep Link + Manual Log
- WhatsApp
- Zalo
- Facebook
- Phone call

## Thread Model

- Each service item has:
  - one thread
  - message timeline

## Message Types

- outbound
- inbound
- note

## Logging Rule

All communication MUST be logged into thread.
