# MOBILE OPS RULES

## Principle
Mobile is optimized for task execution and communication.

## Main Use Cases
- view tasks
- call supplier
- send SMS
- send email
- open WhatsApp / Zalo
- add note
- update task status

## Rule
Every important task should provide quick contact actions.

## Logging
After communication, user should be able to add a quick note to the related thread.

## Non-goals
- full tour builder
- full pricing setup
- full site studio
