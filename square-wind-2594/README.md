# Tour Booking Management (Edge-first, Cloudflare Workers + D1)

Mục tiêu: Quản lý tour đa-điểm-đến (destination), số đêm, mini-card dịch vụ (Accommodation, Meals, Guide, Local, Intercity), thread liên lạc (email/SMS/Zalo/WhatsApp/call notes), auto To-Do khi booking được đặt.
