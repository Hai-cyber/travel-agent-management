Property Builder

Inventory First. Rates Second. Availability Always Tells The Truth.

This page is the first real admin surface for the standalone property engine. Configure the property, define room types, generate physical room units by quantity, assign a base nightly rate, and test availability without touching SQL fixtures.

Inventory backbone: property, room type, and room unit quantity feed directly into availability.
Commercial layer: base nightly rate is kept separate from availability truth so pricing can evolve later without weakening inventory logic.

Tenant Context

Pass ?tid=<tenantId> once. The page remembers it locally for the next visit.

This builder requires a signed-in actor for that tenant. If you type ten-demo-001 but your current session does not belong to that tenant, the APIs will correctly return 403 Forbidden.
